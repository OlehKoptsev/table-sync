Privacy Policy

Last updated: 28 September 2026

What data Table Sync accesses

Table Sync uses the Google Drive permission drive.file. With it, Table Sync can see and edit only the files it creates itself. It cannot see, open or list any other files in your Google Drive.

How the data is used

Table Sync creates a new Google Sheets file in your Drive and shares it with the owner's own automation account, so that sales summaries can be written into it. That is the only thing the permission is used for.

Storage and sharing

Table Sync does not sell, rent or transfer any data to third parties. It does not copy file contents anywhere outside Google. The only thing stored is the access token that lets it create files, kept as a secret in the owner's own cloud environment.

Revoking access

You can remove Table Sync's access at any time at myaccount.google.com/permissions. Files it already created stay in your Drive and remain yours.
